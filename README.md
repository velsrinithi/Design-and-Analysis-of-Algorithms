# Design-and-Analysis-of-Algorithms
A comprehensive collection of Design and Analysis of Algorithms implementations covering Brute Force,Divide and Conquer,Dynamic Programming,Backtracking,and Branch and Bound techniques.
This repository contains implementations of core concepts from Design and Analysis of Algorithms (DAA). It showcases multiple problem-solving paradigms used to design efficient and optimized solutions.

The repository includes:

- Brute Force Approach  
  Basic approach that explores all possible solutions without optimization.

- Divide and Conquer  
  Breaks problems into smaller subproblems, solves them independently, and combines the results (e.g., Merge Sort, Quick Sort).

- Greedy Algorithms  
  Builds solutions step-by-step by choosing the locally optimal option at each stage.

- Dynamic Programming  
  Optimized approach that solves overlapping subproblems using memoization or tabulation.

- Backtracking  
  Systematically explores all possible solutions and backtracks when a solution path fails (e.g., N-Queens, Sudoku).

- Branch and Bound  
  Efficient technique for solving optimization problems by pruning unnecessary branches.

Each implementation is written clearly with proper structure to help understand the logic and approach behind the algorithms.

This repository is useful for:
- Learning fundamental DAA concepts
- Preparing for coding interviews and exams
- Understanding different algorithmic strategies

Language used: c++
